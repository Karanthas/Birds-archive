# R5负结果后的选型路线决定

状态：待用户选择；不是新协议冻结、模型安装授权或选型通过。

## 已确认事实

R5 的七张新验证图只运行一次：六张单鸟第一候选正确；自然煤山雀与蓝山雀照片的前两名也分别是这两种。原始分数差为0.02163296937942505，超过固定校准阈值0.015，所以旧协议将它记为separated，违反“所有自然多鸟必须close/unknown”的零unsafe判据。原科学失败、消费记录和资源收尾失败永久保留，不能改线后重新声称本轮通过。

完整原件：[R5实际结果](../../.planning/phases/03-recognition-batch-review/evidence/03-10/selection-calibration-r5/actual-run/result.md)、[root独立复核](../../.planning/phases/03-recognition-batch-review/evidence/03-10/selection-calibration-r5/actual-run/root-review-verification.json)。公开便利样本不代表私人照片准确率，分数不是概率。

## 路线一：保留BioCLIP2排序候选，完整鸟种集合交人工确认（建议）

这更贴合已确认的个人相册流程：模型给候选，用户确认或补选鸟种后才归档。全图相似度分数差只能描述两个候选分数是否接近，不能证明照片只有一种鸟，也不能证明候选已经列全。

若选择此路线，先建立独立的新版本协议，再使用全新、推理前冻结的公开验证图和真实三模式审核验证：

- 保留原14校准及其输出已被观察的披露；不按R5结果手填或调高阈值。
- 新协议不再把高分差当作“单鸟/完整集合”的证明，不再以自然多鸟必须close/unknown作为自动识别能力承诺。原unsafe统计仍如实报告，不隐藏R5失败。
- 单鸟Top1/Top3、多鸟完整/部分Top3覆盖全部按固定分母报告。低分差仍可作谨慎提示，未校准分数不得称概率。
- 所有提交仍须明确人工操作；单张和批量预览均允许搜索、补选第二种、跳过或主动无法确定。自然双鸟最终确认必须含完整真值，任何错误确认不因后续改对而抹去。
- 继续要求逐张JPEG/数据库一致、零自动归档、人工版本保护、全部跳过及补做计入分母、两个辅助方式纠正负担不高于纯手动且至少一个严格更低。
- 资源、离线、故障恢复、真实监听与连续收尾门禁不降；下一观测版本必须在新run实证通过。新协议及helper另建版本，不改旧R5或旧科学helper。

无需下载另一个模型。此选择不等于立即选定BioCLIP2，仍须完成新协议、前瞻材料冻结、NAS实际审核与资源门禁，才能形成选型记录。

## 路线二：保留原严格多鸟判据，比较轻量BioCLIP1

继续要求所有自然多鸟close/unknown、零unsafe-separated，并只做一次有停止条件的轻量候选实测。BioCLIP1也是整图CLIP分类器，官方资料没有证据表明更小的模型会修复这次分数差问题；结果未知。

已准备[精确候选审阅](bioclip1-candidate-review/review.md)和[材料清单](bioclip1-candidate-review/inventory-proposed.json)：四项固定来源共598,614,148字节（约599 MB），现有36包可复用；需要独立的候选源码封存、严格weights-only转换、重新生成512维文本特征、重新拟合阈值及另外的新验证图。原BioCLIP2特征和阈值不能复用。当前没有下载权重或安装。

清单项目canonical SHA256为1b7fcd5f24406e81223e30c15cb3dc3b68411c51a2c7012060387e85ae16169f；JSON采用UTF-8、ensure_ascii=false、sort_keys=true、compact分隔、无尾换行。该提议的命名空间和新验证材料还需具体冻结；选择路线二只授权继续完成该方案的实现与审阅准备，尚不授权未定范围的NAS写入或模型下载。具体材料和运行范围齐备后才处理新增授权。

## 为什么需要决定

路线一改变未来验收中对自动多鸟判断的能力承诺，不能由执行者把既有失败自行改判；路线二新增此前精确授权之外的模型材料和兼容实现。两条都可以保留现有人工归档目标，但后续工作与验收含义不同。用户选择前，不执行依赖该选择的新协议/模型/NAS运行。
